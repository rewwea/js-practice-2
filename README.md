**Дисциплина:** Язык сценариев JavaScript и библиотека jQuery

## Цель работы

Закрепить основы языка JavaScript, научиться получать данные от пользователя с помощью `prompt()`, выводить результаты через `alert()`, выполнять математические операции и работать с переменными и константами.

## Выполнение работы

### Задание 1

Пользователь вводит число. Программа возводит его во вторую степень и выводит результат.

Для возведения в степень используется оператор `**`.

```javascript
let number = Number(prompt('Введите число:'))
let square = number ** 2

alert('Число во второй степени: ' + square)
```

### Задание 2

Пользователь вводит два числа. Программа вычисляет их среднее арифметическое.

```javascript
let average = (number1 + number2) / 2
```

Перед вычислением значения, полученные через `prompt()`, преобразуются в числа с помощью `Number()`.

### Задание 3

Пользователь вводит длину стороны квадрата. Площадь рассчитывается по формуле:

```text
S = a²
```

В JavaScript:

```javascript
let area = side ** 2
```

### Задание 4

Реализован конвертер километров в мили.

Коэффициент перевода записан как константа:

```javascript
const KM_TO_MILES = 0.621371
```

Количество миль рассчитывается умножением количества километров на данный коэффициент.

### Задание 5

Реализован простой калькулятор. Пользователь вводит два числа, после чего программа выполняет четыре арифметических действия:

- сложение;
- вычитание;
- умножение;
- деление.

Все результаты выводятся пользователю с помощью `alert()`.

### Задание 6

Программа получает значения `a` и `b` и находит `x` для уравнения:

```text
a * x + b = 0
```

Для нахождения `x` используется формула:

```text
x = -b / a
```

### Задание 7

Пользователь вводит текущее время в часах и минутах.

Программа переводит время в минуты, вычисляет количество минут до конца суток, после чего переводит полученное значение обратно в часы и минуты.

Для получения остатка минут используется оператор `%`.

### Задание 8

Пользователь вводит трехзначное число. Программа определяет вторую цифру числа.

Используется деление и оператор остатка от деления `%`:

```javascript
let secondDigit = Math.floor(threeDigitNumber / 10) % 10
```

### Задание 9

Пользователь вводит пятизначное число. Последняя цифра числа переносится в начало.

Например:

```text
12345 → 51234
```

Последняя цифра определяется с помощью:

```javascript
fiveDigitNumber % 10
```

Оставшаяся часть числа получается с помощью `Math.floor()`.

### Задание 10

Пользователь вводит общую сумму продаж за месяц.

Зарплата рассчитывается как фиксированная ставка 250 и 10% от общей суммы продаж:

```javascript
let salary = BASE_SALARY + sales * SALES_PERCENT
```
